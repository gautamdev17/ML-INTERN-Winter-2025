Research project on applying Machine Learning to EEG (Electroencephalogram) data as part of my Winter 2025 internship (Dec 2025) under Dr. Kannadasan K, Assistant Professor, IIITDM Kancheepuram. The work focuses on solving challenging EEG problems through signal preprocessing, feature extraction, and supervised learning, with applications in Brain-Computer Interfaces (BCI) and Affective Computing.
