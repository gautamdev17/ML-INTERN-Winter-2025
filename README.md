# EEG-ML Research

Personal research repo exploring **Machine Learning for EEG (Electroencephalogram) data** with applications in Brain-Computer Interfaces (BCI) and Affective Computing.  
The focus is on applying supervised learning, model evaluation, and preprocessing techniques to real-world EEG signals.

---

## 📌 Goals
- Build intuition and hands-on skills in **EEG signal processing + ML**  
- Work with datasets like **Iris, Pima Diabetes**, and gradually shift to **EEG datasets**  
- Practice **model evaluation**: accuracy, confusion matrix, precision, recall, F1, ROC  
- Explore **supervised learning models** (Logistic Regression, SVM, Decision Trees, Neural Nets)  
- Lay foundation for **internship work (December 2025)** in EEG + ML  

---

## 🚀 Tech Stack
- **Languages**: Python  
- **Libraries**: NumPy, Pandas, Scikit-learn, Matplotlib  
- **Concepts**: Preprocessing, Supervised Learning, Model Evaluation, Feature Engineering
